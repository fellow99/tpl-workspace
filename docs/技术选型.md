# 技术选型

参考RuoYi-Vue-Plus的技术选型

---

## 技术栈概览

### 架构模式
- **架构风格：** 前后端分离 + 多平台前端
- **后端架构：** Spring Boot 四层分层架构（Controller → Service → Mapper → Entity）
- **Web前端架构：** Vue3 + TypeScript + Element Plus（独立前端项目 plus-ui）
- **安卓前端架构：** 典型安卓脚手架
- **鸿蒙前端架构：** 典型鸿蒙脚手架
- **小程序前端架构：** 典型微信小程序脚手架
- **通信协议：** HTTP/HTTPS + RESTful API
- **数据格式：** JSON
