# 产品概念设计

> 项目：tpl-workspace（多端业务应用框架）
> 版本：v1.0
> 日期：2026-08-22

---

## 一、项目概述

### 1.1 产品定位

tpl-workspace 是一个**多端业务应用框架**，提供跨平台（Web / Android / HarmonyOS / 微信小程序）的业务应用开发底座。

#### 核心能力

- **用户账号体系**：注册、多方式登录（密码/短信/微信）、个人中心、验证码
- **多端覆盖**：Web + Android + HarmonyOS + 微信小程序，模块编号跨端对齐
- **框架继承**：管理后台继承 RuoYi-Vue-Plus，用户侧独立轻量工程
- **安全基线**：BCrypt 密码加密、AES+RSA 传输加密、Sa-Token 认证
- **桌面工作台**：整体平台的前端门户（统一入口），多页面可视化桌面应用（wujie 微前端宿主 + 插件子应用）

## 二、功能模块规划

### 2.1 用户模块（user-auth）

- 用户注册（手机号 + 密码 + 验证码）
- 用户登录（密码 / 短信 / 微信三种方式）
- 个人中心（查看/修改个人信息、修改密码）
- 设计文档：[002-用户注册及登录设计.md](002-用户注册及登录设计.md)

### 2.2 基础设施模块

| 模块 | 说明 |
|------|------|
| 国际化（i18n） | 多语言支持，语料单一事实源 |
| 主题皮肤（theme） | 亮色/深色/跟随系统三态切换 |
| 短信平台对接 | Spug Push 短信验证码发送 |
| 应用外壳（app-shell） | 各端应用骨架、路由、导航 |

### 2.3 桌面工作台模块（desktop，前端门户）

> 桌面工作台是整体平台的一个前端模块（统一入口 · 前端门户），模块编号采用**桌面线自有编号**（`001`~`401`、`006`/`007`），与多端业务框架的模块编号（`002`/`004`/`005`/`202`）相互独立、不冲突。

| 编号 | 模块 | 说明 |
|------|------|------|
| 001 | 桌面框架 | 多页面桌面编排、GridStack 网格、编辑/浏览双模式、配置持久化 |
| 002 | 小部件系统 | 拖拽添加/缩放/删除，属性可视化编辑，元数据自动注册 |
| 003 | App 应用系统 | 全屏叠加层运行，最小化/恢复/关闭，应用市场与快捷方式 |
| 004 | 背景系统 | 12 套预设（浅色/深色/动态视频 ×4），分类轮播选择 |
| 005 | 主题系统 | 浅色/深色双主题，CSS 变量（--desktop-*）驱动，防闪烁加载 |
| 006 | 图标字体 | 图标/Emoji 资源与渲染 |
| 007 | wujie 系统 | wujie 微前端宿主接入、插件子应用加载 |
| 011 | 模拟认证 | RSA 加密登录，后端不可达时自动降级 mock，会话持久化 |
| 101 | 属性编辑器 | el-drawer 动态表单，类型映射驱动渲染，编辑副本隔离 |
| 201 | 桌面入口页 | 启动全链路（HTML→JS→Vue），运行时配置注入，反 FOUC |
| 301 | 基础小部件 | 5 个内置 Widget：文字、数字（动画）、Markdown、图片、视频 |
| 401 | 基础应用 | 2 个内置 App：数字时钟（dayjs）、iframe 网页嵌入 |

> 桌面工作台插件子应用 `tpl-desktop-plugin-demo` 的模块：`001-wujie-adaptor`、`002-demo-widgets`、`003-demo-app`、`004-demo-backgrounds`，详见其 `specs/README.md`。

## 三、整体架构

### 3.1 子工程清单

| 子工程 | 名称 | 说明 |
|--------|------|------|
| tpl-app-android | tpl-workspace Android 端 | Android 原生 App |
| tpl-app-harmony | tpl-workspace 鸿蒙端 | HarmonyOS 原生 App |
| tpl-app-mini | tpl-workspace 微信小程序端 | 微信小程序 |
| tpl-app-web | tpl-workspace 网页端 | Vue 3 + TypeScript |
| tpl-app-api | tpl-workspace 后端（用户侧） | Spring Boot 独立工程 |
| tpl-manage | Admin 后台管理 | 基于 RuoYi-Vue-Plus |
| tpl-manage-ui | Admin 后台管理前端 | 基于 RuoYi-Vue-Plus-UI |
| tpl-desktop | 桌面工作台（前端门户） | wujie 微前端宿主（多页面可视化桌面） |
| tpl-desktop-plugin-demo | 桌面工作台插件示例 | wujie 微前端子应用 |

### 3.3 桌面工作台架构（前端门户）

```
tpl-desktop（桌面工作台 · wujie 微前端宿主，多页面可视化桌面）
  │  通过 public/PLUGINS.json 配置加载子应用
  ▼
tpl-desktop-plugin-demo（wujie 微前端子应用）
  │  import.meta.glob 自动扫描注册 Widget / App / 背景 / UI 组件
  │  window.__POWERED_BY_WUJIE__ 双模式（沙箱 / 独立调试）
  ▼
$wujie.bus.$emit('plugin:ready') ──▶ 宿主 app.component() 注册组件 + 注入元数据
```

桌面工作台是整体平台的一个**前端模块**（统一入口 · 前端门户）。当前为纯前端实现：认证采用 RSA 加密 + mock 降级，配置通过 `localStorage` 持久化；后续可接入 `tpl-app-api` 实现真实认证与业务数据。宿主与子应用通过 wujie 事件总线通信。

### 3.4 服务间通信

| 调用方向 | 方式 | 说明 |
|---------|------|------|
| 客户端 → tpl-app-api | REST API（Sa-Token JWT） | 用户侧业务请求 |
| 客户端 → tpl-manage | REST API（Sa-Token RBAC） | 管理后台请求 |
| tpl-app-api/tpl-manage → PostgreSQL | JDBC | 共享业务数据库 |
| tpl-app-api/tpl-manage → Redis | Redisson/Lettuce | 缓存/会话/验证码 |

## 四、核心决策记录

### 4.1 技术选型

| 决策项 | 结论 |
|--------|------|
| 后端框架 | Spring Boot 4.1（双后端统一） |
| 数据库 | PostgreSQL + Redis |
| 对象存储 | MinIO |
| 前端框架 | Vue 3 + TypeScript（用户侧无 UI 框架，管理端 Element Plus） |
| 认证框架 | Sa-Token（JWT / RBAC） |
| 移动端 | Kotlin / ArkTS / 微信小程序 |
| 桌面工作台 | Vue 3.5 + Vite 8 + Element Plus + GridStack + Swiper + wujie（纯前端） |

### 4.2 架构决策

| 决策项 | 结论 |
|--------|------|
| 数据共享 | tpl-app-api 和 tpl-manage 共享 PostgreSQL + Redis + MinIO |
| 管理后台基础 | tpl-manage 基于 RuoYi-Vue-Plus，tpl-manage-ui 基于 RuoYi-Vue-Plus-UI |
| RuoYi 标准表 | 不做任何修改，业务通过 `tpl_*` 扩展表实现 |
| 桌面工作台 | 整体平台前端门户（统一入口，wujie 微前端宿主 + 插件子应用），纯前端，localStorage 持久化，后续接入 tpl-app-api |

## 五、命名规范

### 5.1 数据库命名

| 类型 | 格式 | 示例 | 说明 |
|------|------|------|------|
| RuoYi 标准表 | `sys_*` | `sys_user`、`sys_config` | 不做任何修改 |
| 业务表 | `tpl_<功能名称>` | `tpl_user_profile` | 业务扩展表 |
| 业务视图 | `tpl_<功能名称>_view` | `tpl_user_view` | 糅合 RuoYi 标准表与业务表 |

### 5.2 模块中英文对照

| 中文 | 英文（代码用） | 英文（文档用） |
|------|--------------|---------------|
| 用户 | `user` | User |
| 注册 | `register` | Register |
| 登录 | `login` | Login |
| 个人中心 | `profile` | Profile |

## 六、数据库核心表规划

| 表名 | 类型 | 说明 |
|------|------|------|
