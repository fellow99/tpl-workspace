# 202 短信平台 API 对接

> 模块编号：202-sms-integration
> 对接平台：Spug Push（https://push.spug.cc）
> 涉及工程：父工程、tpl-app-api
> 更新日期：2026-08-14

---

## 一、概述

对接 Spug Push 短信平台，实现**短信验证码发送**功能。当前使用平台官方模板，模板编码 `TEMPLATE_CODE` 通过 `application.yml` 配置。在 tpl-app-api 中封装一个功能类（`SmsService`），供注册、登录、找回密码等其他业务模块调用。

---

## 二、接口文档

### 2.1 请求地址

```
POST https://push.spug.cc/sms/<TEMPLATE_CODE>
```

### 2.2 请求参数

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| TEMPLATE_CODE | string | 是 | 路径参数，短信模板编码 |
| to | string | 是 | 接收手机号；多个号码用英文逗号分隔，单次最多 5 个 |
| code | string | 是 | 4 至 6 位数字或字母验证码 |
| number | string | 否 | 选择带有效时长的模板时必填，表示有效分钟数 |

### 2.3 请求示例

```bash
curl 'https://push.spug.cc/sms/<TEMPLATE_CODE>' \
  -H 'Content-Type: application/json' \
  -d '{"to":"13800000000","code":"153146"}'
```

### 2.4 响应示例

```jsonc
{
  "code": 200, // 200 表示请求成功
  "msg": "请求成功", // 成功时显示"请求成功"，失败时说明具体原因
  "request_id": "N6KQ8m2W4xY7p9aB" // 用于查询发送状态
}
```

---

## 三、短信内容

使用平台官方模板，通过 `/sms` 向请求中指定的手机号发送验证码：

> 您的验证码是${code}，十分钟内有效，如非本人操作请忽略。

---

## 四、实现要点

1. 模板编码（`TEMPLATE_CODE`）作为调用凭证，必须由业务服务端发起，不能放入网页或移动端安装包。
2. 当前使用 `TEMPLATE_CODE`：`5nI_gjqEQV-dxQWrW5aIMg`，配置到 `tpl-app-api/src/main/resources/application.yml`。
3. 封装 `SmsService`，提供 `sendCode(phone)`（缓存去重发送）、`verifyCode(phone, code)`（消费校验）、`sendVerificationCode(phone, code)`（底层发送）三个方法，其他模块注入调用。

---

## 五、验证码缓存与消费机制

| 项 | 说明 |
|----|------|
| 缓存键 | Redis `sms_code:{手机号}` |
| 有效期 | 10 分钟 |
| 去重 | 一个手机号仅缓存一个验证码；未过期则不重新生成/发送 |
| 消费 | `verifyCode(phone, code)` 一致则清空缓存返回 true，否则 false |

---

## 六、排错

请求被拒绝时，依次检查：模板编码、模板变量、手机号格式、实名状态、短信额度、IP 白名单。

- 查询发送状态：https://push.spug.cc/guide/request/query
- 发送记录：https://push.spug.cc/console/records
- IP 白名单：https://push.spug.cc/console/developer/security
