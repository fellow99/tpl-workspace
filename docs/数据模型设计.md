## 一、数据库设计规范

### 1.1 命名规范

| 类型 | 命名格式 | 示例 | 说明 |
|------|---------|------|------|
| RuoYi 标准表 | `sys_<名称>` | `sys_user`、`sys_config`、`sys_social`、`sys_client` | **不做任何修改** |
| 业务表 | `tpl_<名称>` | `tpl_user_profile` | 业务扩展表 |
| 业务视图 | `tpl_<名称>_view` | `tpl_user_view` | 糅合 RuoYi 表与业务表 |
| 字段名 | 全小写 + 下划线 | `user_id`、`birth_date`、`create_time` | 与 RuoYi 风格一致 |
| 唯一索引名 | `uk_<表>_<字段>` | `uk_user_profile_user_id` | — |
| 外键名 | `fk_<表>_<关联表>` | `fk_profile_user` | — |

### 1.2 基础字段约定

业务表 `tpl_*` 包含以下标准字段：

| 字段 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `id` | `BIGINT` | 自增 | 主键（独立业务表） |
| `create_time` | `DATETIME` | `CURRENT_TIMESTAMP` | 创建时间 |
| `update_time` | `DATETIME` | 自动维护 | 更新时间 |
| `del_flag` | `CHAR(1)` | `'0'` | 删除标记：`0`=正常，`2`=已删除 |

> **与 RuoYi 的关系**：`tpl_*` 表不继承 RuoYi BaseEntity，定义自己的基础字段集合。

### 1.3 索引策略

| 原则 | 说明 |
|------|------|
| 外键必建索引 | 所有关联外键字段建立普通索引 |
| 高频筛选字段 | 用户 ID 等筛选字段建立索引 |
| 唯一约束 | 业务唯一性字段使用 UNIQUE 约束 |

### 1.4 外键与软删除

| 策略 | 说明 |
|------|------|
| 级联删除 | **不使用** CASCADE DELETE，统一通过 `del_flag` 软删除 |
| 软删除 | 所有 `tpl_*` 表使用 `del_flag = '0'` 表示正常数据 |

## 三、业务表

### 3.1 用户扩展表 — tpl_user_profile

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| `profile_id` | `BIGINT` | PK, 自增 | 主键 |
| `user_id` | `BIGINT` | NOT NULL, UNIQUE, FK → sys_user.user_id | 关联用户 |
| `birth_date` | `DATE` | — | 出生日期（选填） |
| `create_time` | `DATETIME` | NOT NULL | 创建时间 |
| `update_time` | `DATETIME` | NOT NULL | 更新时间 |

```sql
CREATE TABLE tpl_user_profile (
    profile_id      BIGINT       PRIMARY KEY AUTO_INCREMENT,
    user_id         BIGINT       NOT NULL UNIQUE,
    birth_date      DATE,
    create_time     DATETIME     NOT NULL DEFAULT CURRENT_TIMESTAMP,
    update_time     DATETIME     NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    CONSTRAINT fk_profile_user FOREIGN KEY (user_id) REFERENCES sys_user(user_id),
    CONSTRAINT uk_profile_user_id UNIQUE (user_id)
);

COMMENT ON TABLE tpl_user_profile IS '用户扩展信息表';
```

### 3.2 用户视图 — tpl_user_view

```sql
CREATE VIEW tpl_user_view AS
SELECT
    u.user_id,
    u.user_name,
    u.nick_name,
    u.phone_number,
    u.password,
    u.avatar,
    u.status,
    u.del_flag,
    u.login_ip,
    u.login_date,
    u.create_time,
    p.birth_date
FROM sys_user u
LEFT JOIN tpl_user_profile p ON u.user_id = p.user_id
WHERE u.del_flag = '0';
```

## 五、数据字典

### 5.1 设计说明

RuoYi-Vue-Plus 使用 `sys_dict_type` / `sys_dict_data` 两张标准表管理数据字典，本框架**不做任何 DDL 修改**，仅通过 INSERT 新字典扩展。

| 操作 | 表 | 说明 |
|------|-----|------|
| 新增字典项 | `sys_dict_data` | INSERT 每项数据 |
| 管理员维护 | tpl-manage | 使用 RuoYi「字典管理」界面 |
| 前端获取 | REST API | `GET /system/dict/data/type/{dictType}` |

> 字典类型命名统一使用 `tpl_` 前缀。
